# API модерации объявлений

## Запуск

Проверено на Python 3.13. Выполни команды из корня репозитория.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
fastapi dev
```

OpenAPI доступна по адресу `http://127.0.0.1:8000/docs`. `GET /` возвращает
`{"message": "Hello World"}`.

## POST /predict

Все семь полей JSON обязательны. API проверяет типы без преобразования значений,
отклоняет неизвестные поля и принимает только неотрицательное количество изображений.

```bash
curl http://127.0.0.1:8000/predict \
  -H 'Content-Type: application/json' \
  -d '{"seller_id":1,"is_verified_seller":false,"item_id":42,"name":"Велосипед","description":"В хорошем состоянии","category":3,"images_qty":0}'
```

Ответ на этот запрос — `true`.

| Код | Тело ответа |
| --- | --- |
| 200 | Булево значение. `true` означает нарушение и возвращается для неподтверждённого продавца при нуле изображений. Для подтверждённого продавца или объявления с изображениями возвращается `false`. |
| 400 | Объект с массивом `detail`. У каждой ошибки есть путь к полю (`loc`), сообщение (`msg`) и тип (`type`). |
| 500 | `{"detail":"Не удалось проверить объявление"}`. Подробности исключения записываются в журнал сервиса. |

HTTP-обработчик принимает запрос и вызывает сервис. Сервис применяет правило модерации,
а репозиторий хранит порог для неподтверждённых продавцов в коде.
